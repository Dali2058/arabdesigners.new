# Arab Designers — Contact / Tickets

The website sends a contact ticket notification directly to the configured Discord webhook.

A real two-way **Your Tickets** web chat (messages, image/file uploads, voice messages, Close Ticket, and Discord channel synchronization) requires a Discord bot/backend. GitHub Pages is static and cannot securely read Discord channel messages or keep a bot token private.

Do not place a Discord bot token in `app.js` or any GitHub Pages file.
