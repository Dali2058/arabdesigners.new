# Arab Designers Admin

1. Run `supabase/schema.sql`.
2. Run `supabase/migration_views.sql`.
3. Run `supabase/migration_admin.sql`.
4. Deploy `supabase/functions/arab-designers-api/index.ts` as `arab-designers-api`.

The protected admin username is `i.ixi.`. The admin can verify designers and grant/remove the Staff badge.

The public Add Work / Upload system has been removed from this build.
